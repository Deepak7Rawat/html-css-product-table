## ✦ About

This project demonstrates how to create and style a **product table using HTML and CSS**.

It includes product details such as **quantity, per-unit price, amount, and total**, with a simple row hover effect.

---

## ✦ Features

* Structured HTML table
* Product and pricing details
* Total amount row
* Centered table layout
* Styled table headers
* Row hover effect
* Simple and clean design
